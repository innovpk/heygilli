# Peeku

An AI co-watching buddy for kids' YouTube. Peeku the squirrel watches alongside a child on a tablet or phone, pauses every few minutes to ask a question by voice, and tells the parent at the end of the day what their kid learned.

Built for the **Agents for Humans** hackathon (AWS × Devpost), Everyday Agents track, on the **Strands Agents SDK**.

## What it is

- **Kid mode** (Flutter, phone and tablet, TV next): only parent-approved YouTube channels, official YouTube embed, no recommendations, no search. Peeku pauses the video at natural breaks and asks. A 4-year-old answers with one word or a tap; a 10-year-old answers in a sentence, in English or Urdu.
- **The parent's agent** (Python, Strands): four agents run in the background. *Curator* screens new uploads and asks the parent only about borderline ones. *Planner* turns a video into age-banded questions. *Buddy* runs the live session. *Digest* writes the nightly two-line report and decides whether anything deserves a notification.
- **Provider-flexible by design.** Each agent's model is one config line: Amazon Bedrock by default, Anthropic, OpenAI, or Ollama as alternates. Same agents, same eval, any provider.

## Run the agents locally

```bash
cd agents
uv venv --python 3.12 && uv pip install -e ".[dev]"
cp .env.example .env            # fill in AWS creds or an ANTHROPIC_API_KEY
uv run python -m peeku_agents.hello
# swap provider with one line:
PEEKU_MODEL_PLANNER=anthropic:claude-opus-5 uv run python -m peeku_agents.hello
```

## Run the app

```bash
cd app
flutter pub get
flutter run            # phone or tablet, Android 12+
```

## Honest notes

- Ads on YouTube still play. Peeku uses the official embed and never blocks, downloads, or overlays playback.
- Nothing a child says is stored. Answers keep a score and a ten-word paraphrase.
- Reading a public YouTube video's content uses a video-understanding model that accepts YouTube URLs (Gemini) inside one tool; a Bedrock-only build falls back to public captions.
